# ابزار بررسی وضعیت IP، اختلال BGP و پینگ مستقیم به سرورهای VPN

ابزار تحت وب سبک، سریع و کاملاً رایگان برای عیب‌یابی اتصال اینترنت و سرورهای VPN (به‌ویژه سرورهای شخصی و پنل‌هایی مانند `panel.*`).

---

## 🚀 ویژگی‌های کلیدی

1. **بررسی تطبیقی BGP داخلی (۶۴۱ پیشوند `/21` ایرانسل):**
   - بدون نیاز به آپلود هیچ فایلی (اطلاعات در فایل `bgp_data.js` تعبیه شده است).
   - تشخیص وضعیت رنج IP اپراتور: 🟢 احتمالاً سالم | 🔴 احتمالاً خراب | 🟡 نامشخص.
   - کارت‌های راهکار هوشمند (مانند فعال‌سازی ۱۰ ثانیه‌ای حالت هواپیما جهت دریافت رنج جدید IP).

2. **⚡ تست پینگ مستقیم از دستگاه شما (گزینه A - بدون واسطه):**
   - پینگ و محاسبه دقیق زمان رفت‌وبرگشت (RTT به میلی‌ثانیه) مستقیماً از مرورگر و اینترنت فعلی شما (سیم‌کارت یا مودم).
   - پینگ به:
     - `panel.*` (سرور اختصاصی شما — دامنه مستقیماً توسط خودتان در مرورگر وارد می‌شود و در مخزن عمومی ذخیره نمی‌گردد)
     - `google.com` (اینترنت بین‌الملل)
     - `cloudflare.com` (شبکه جهانی)
     - `1.1.1.1` (DNS امن)
     - `aparat.com` (اینترنت داخلی برای تشخیص ملی شدن شبکه)
   - امکان افزودن هر دامنه یا IP دلخواه با کلیک یک دکمه.
   - تشخیص تفاوت مسدودسازی فوری (TCP RST)، تایم‌اوت (Blackhole) و اتصال موفق.

3. **☁️ تست تطبیقی از سرور ابری Cloudflare Worker (اختیاری):**
   - امکان سوئیچ به حالت سرور ابری برای مقایسه وضعیت: آیا سرور از خارج ایران آنلاین است و فقط در ایران فیلتر شده؟

## 📁 ساختار مخزن

```
vpn-ip-checker/
├── index.html          # کل وب‌اپ (HTML + CSS + جاوااسکریپت پینگ و BGP)
├── bgp_data.js         # پایگاه داده تعبیه‌شده ۶۴۱ رنج BGP ایرانسل (۶۲ کیلوبایت)
├── worker.js           # کد Cloudflare Worker (برای پینگ اختیاری از خارج)
└── README.md           # راهنمای کامل
```

---

## 🌐 روش انتشار روی GitHub Pages (کاملاً رایگان در ۲ دقیقه)

1. یک مخزن جدید در [github.com/new](https://github.com/new) بسازید (نام دلخواه، مثلاً `vpn-ip-checker` و حالت **Public**).
2. فایل‌های این مخزن (`index.html`، `bgp_data.js`، `worker.js`، `README.md`) را در آن آپلود کنید.
3. در گیت‌هاب وارد **Settings** ← **Pages** شوید.
4. زیر بخش **Build and deployment**، گزینه Branch را روی `main` و پوشه را روی `/ (root)` بگذارید و **Save** کنید.
5. لینک وب‌سایت شما فوراً آماده است:
   ```text
   https://USERNAME.github.io/vpn-ip-checker/
   ```
   این لینک را به راحتی در گوشی یا کامپیوتر خود و اعضای خانواده باز کنید!

## ☁️ استقرار اختیاری Cloudflare Worker (برای تست از خارج از کشور)

اگر مایلید پینگ از سرورهای ابری خارج از کشور را هم در کنار پینگ مستقیم دستگاه داشته باشید:
1. در داشبورد [Cloudflare](https://dash.cloudflare.com/) به بخش **Workers & Pages** بروید.
2. دکمه **Create application** ← **Create Worker** را بزنید.
3. کد پیش‌فرض را پاک کرده و محتوای فایل `worker.js` را داخل آن قرار دهید و **Deploy** کنید.
4. آدرس ورکر خود را (مثلاً `https://vpn-ping.YOURS.workers.dev`) در خط ۲۱۱ فایل `index.html` داخل متغیر `WORKER_URL` قرار دهید.

## 💡 نکات امنیتی و حریم خصوصی

- پینگ گزینه A به هیچ سرور واسطه‌ای متصل نمی‌شود و کاملاً درون مرورگر کاربر اجرا می‌گردد.
- شناسایی IP از طریق سرویس‌های عمومی و استاندارد (`ipify`, `my-ip.io`, `ipwho.is`) با لایه محافظتی Timeout انجام می‌گیرد.
- نیازی به نصب اپلیکیشن، دسترسی روت یا تغییر تنظیمات امنیتی وجود ندارد.
